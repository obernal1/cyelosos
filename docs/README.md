# Documentación del proyecto CyelOS / Cyelos

Landing orientada a **logros financieros** (ahorro, eficiencia, soporte claro). Stack: Next.js (App Router), Tailwind CSS, Lucide React, Framer Motion.

## Archivos de contexto

- **CONTEXTO_NEGOCIO.md** – Propuesta de valor, tono consultivo, oferta, datos legales (NIT, ciudad).
- **DISEÑO_UX.md** – Paleta cyelos.com (`#E84848`, `#404040`, `#FFFFFF`), tipografía Inter, SEO y JSON-LD.
- **ESTRUCTURA_LANDING.md** – Orden de secciones, anclas (`#cuestionario`, `#la-solucion-cyelos`, etc.) y copy base.

## Variables de entorno

Ver `.env.example` en la raíz del repo (`NEXT_PUBLIC_SITE_URL` para URLs absolutas en datos estructurados).

## Comandos

```bash
npm run dev    # desarrollo
npm run build  # producción
```

Deploy recomendado: **Vercel**.
