# Cyelos – Landing Page

Landing de alta conversión para Cyelos (pymes Colombia). Stack: Next.js (App Router), Tailwind CSS, Lucide React, Framer Motion. Deploy en Vercel.

## Documentación de contexto
- **CONTEXTO_NEGOCIO.md** – Propuesta de valor, tono, público objetivo.
- **DISEÑO_UX.md** – Paleta, estilo visual, responsive, componentes.
- **ESTRUCTURA_LANDING.md** – Secciones y contenido de la landing.

## Desarrollo
```bash
npm run dev
```
## Build y deploy (Vercel)
```bash
npm run build
npm run start
```
Conectar el repo a Vercel para despliegue automático.
